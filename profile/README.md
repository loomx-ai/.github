# LoomX

**Open-source tools for cloud visibility and control.**

We build tools that help teams understand their cloud infrastructure and make informed changes.

## Meet Steward

[Steward](https://github.com/loomx-ai/steward) brings **AWS, Azure, Google Cloud, and Alibaba Cloud** into one interface.

- **Discover resources** across cloud accounts.
- **Explore dependencies** and understand how resources connect.
- **Review cleanup impact** before execution and follow the results.

Run it yourself or get started with [Steward Cloud](https://steward.console.loomx.ai).

[Product & demo](https://loomx.ai/steward/) · [Documentation](https://loomx.ai/steward/docs/latest/en/) · [Quick start](https://loomx.ai/steward/docs/latest/en/quick-start/) · [Releases](https://github.com/loomx-ai/steward/releases)

## Install & contribute

See the [installation guide](https://loomx.ai/steward/docs/latest/en/installation/) for supported platforms. We maintain [Homebrew and Scoop packages](https://github.com/loomx-ai/homebrew-tap) and [signed APT and RPM repositories](https://github.com/loomx-ai/packages).

[Report an issue](https://github.com/loomx-ai/steward/issues) or read the [development guide](https://loomx.ai/steward/docs/latest/en/development/) to contribute.
